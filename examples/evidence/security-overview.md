# CloudDesk Security Overview

Document owner: Security

Approved: 2026-07-18

Classification: Synthetic demo evidence

## Encryption

CloudDesk encrypts customer content in transit using TLS 1.2 or later. Customer content and production backups are encrypted at rest with AES-256 managed keys.

## Administrative access

Production administrative access requires single sign-on, phishing-resistant multi-factor authentication, and approval through a time-bound access workflow. Access events are logged and reviewed monthly.

## Security testing

CloudDesk commissions an independent penetration test at least annually. Findings are risk-ranked, assigned an owner, and tracked to closure through the vulnerability management program.
